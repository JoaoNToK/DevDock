# Módulo de Estudos — DevDock

> **Status:** Implementado

## Visão Geral

Permite cadastrar matérias de estudo, registrar tópicos com barras de progresso, criar anotações em rich text/markdown e definir metas de aprendizado com rastreamento de horas.

## Arquivos Principais

- Rota: `src/app/estudos/page.tsx`, `src/app/estudos/materias/page.tsx`
- Hook: `src/hooks/useStudies.ts`
- Tipos: `src/types/studies.ts`
