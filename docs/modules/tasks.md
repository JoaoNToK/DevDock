# Módulo de Tarefas — DevDock

> **Status:** Implementado

## Visão Geral

Gerenciador de tarefas integrado. Permite criar, editar, categorizar por prioridades (`urgent`, `high`, `normal`), associar a projetos ou disciplinas e acompanhar o status de conclusão com checklists.

- Componentes: `src/components/TaskManager.tsx`, `TaskFormModal.tsx`
